# 🌱 Root Quest — 語源で覚える英単語

共通の**語源（語根）**を持つ英単語をまとめて出題し、それぞれの意味を答えていく英単語学習ゲームです。
語根のイメージをつかむことで、初めて見る単語も推測できる力が身につきます。

## 特徴

- **語源グループ出題**: `port`（運ぶ）→ import / export / transport … のように、共通の語根を持つ単語をまとめて学習
- **4択クイズ**: 各単語の意味を4つの選択肢から選ぶ形式。誤答にも同じ語根の単語の意味が混ざるので、しっかり区別する力がつく
- **語根の成り立ち表示**: 解答後に `in(中へ)+port(運ぶ)` のような分解を表示
- **学習記録の保存**: プレイ回数・最高正答率・マスターした語根を**ローカルストレージ**に保存
- **語根マスター**: 全問正解した語根には ⭐ が付く
- ダークテーマのスマホ対応UI。サーバー不要・オフライン動作

## 遊び方

ブラウザで `index.html` を開くだけです。

```
# 例: ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000 にアクセス
```

1. ホーム画面で学習したい語根を選ぶ（または「ランダムに出題スタート」）
2. 表示された英単語の意味を4択から選ぶ
3. 全問終わると結果と復習リストが表示される

## ファイル構成

| ファイル     | 内容                                   |
| ------------ | -------------------------------------- |
| `index.html` | 画面構造                               |
| `style.css`  | スタイル（ダークテーマ）               |
| `app.js`     | ゲームロジック・ローカルストレージ処理 |
| `data.js`    | 語根と単語のデータ                     |

## 単語データの追加

`data.js` の `VOCAB_DATA` 配列にグループを追加するだけで問題が増えます。

```js
{
  root: "port",
  rootMeaning: "運ぶ (carry)",
  origin: "ラテン語 portare",
  words: [
    { word: "import", meaning: "輸入する", note: "in(中へ)+port(運ぶ)" },
    // ...
  ],
}
```

## データ保存について

学習記録はブラウザの `localStorage`（キー: `rootquest.progress.v1`）に保存されます。
ホーム画面の「学習記録をリセット」ボタンですべて削除できます。
